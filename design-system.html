AuraPilot · Design System

DesignSystemManifest v1.0 · 强调色 领航青蓝 #3DA9FC（纯色·无渐变）
设计主张：开发者工具美学，参考 Linear / Raycast / Cursor 的气质——信息密度高但不拥挤，克制的色彩（1 个强调色 + 中性灰阶 + 绿/黄/红状态色），暗色优先、浅色同构。 字体刻意避开被禁止清单点名的 Inter，改用 Manrope（几何无衬线，UI 尺寸表现出色）；代码 / ID / 字段名用 JetBrains Mono（依用户指定）。

6 · 应用图标

意象：罗盘 / 舵轮 / 领航员。简洁线性风——外圈细线圆 + 内部青蓝菱形指针（南北针），中心留白圆点。纯 SVG，单色 accent，可随主题着色。

可访问性基线：正文对比度满足 WCAG AA；交互目标 ≥ 44px（工具栏按钮、模态按钮）；状态色均附文字/图标，不靠颜色单通道传达；模态支持焦点陷阱与 Esc 关闭。
